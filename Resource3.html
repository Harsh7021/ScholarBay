Security in Computing: Introduction to Cryptography

April 2, 2026

In an increasingly connected world, protecting data is paramount. Security in Computing (SIC) explores the methodologies used to defend information systems from unauthorized access, use, disclosure, or destruction.

1. The CIA Triad

At the core of information security is the CIA triad, a model designed to guide policies for information security within an organization:

  • Confidentiality: Ensuring that data is accessed only by authorized individuals. (e.g., Encryption, Passwords).
  • Integrity: Ensuring that data is accurate, complete, and trustworthy. (e.g., Checksums, Hashing).
  • Availability: Ensuring that data and systems are accessible to authorized users when needed. (e.g., DDoS mitigation, Hardware backups).

2. Cryptography: Symmetric vs. Asymmetric Encryption

Cryptography is the mathematical foundation of secure communication. There are two primary types of encryption you need to know for your SIC syllabus:

Symmetric Encryption: Uses a single, shared key for both encrypting and decrypting data. It is fast and efficient but requires a secure method to share the key between parties. Examples include AES (Advanced Encryption Standard) and DES.

Asymmetric Encryption: Uses a pair of keys—a public key for encryption and a private key for decryption. Anyone can use the public key to send a secure message, but only the holder of the private key can read it. RSA is the most common algorithm used here.

"Security is a process, not a product."

3. Hashing Algorithms

Unlike encryption, hashing is a one-way function. It takes an input of any length and produces a fixed-size string of characters. Hashes are primarily used to verify data integrity (e.g., checking if a downloaded file has been tampered with) and for securely storing user passwords.

Study these fundamental concepts carefully, as they form the basis for more advanced topics like digital signatures and network security protocols.
